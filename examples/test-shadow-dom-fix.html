🔧 Shadow DOM 修复测试

这个页面用于测试修复后的 Shadow DOM 禁用配置

1. ShareButton 组件测试

预期：应该显示一个 Ant Design 样式的按钮，不应该有 shadow-root

2. HelpLink 组件测试

预期：应该显示一个帮助链接，不应该有 shadow-root

3. 实时状态检查

4. 样式测试

在控制台执行以下 CSS 来测试样式是否生效：

/* 测试 ShareButton 组件 */ share-button button { background-color: red !important; color: white !important; } /* 测试 HelpLink 组件 */ help-link a { color: purple !important; font-weight: bold !important; }

5. 开发者工具检查

  1. 右键点击上面的组件，选择"检查元素"
  2. 在 Elements 面板中查看组件结构
  3. 如果看到 #shadow-root (open)，说明 Shadow DOM 没有被禁用
  4. 如果没有看到 shadow-root，说明 Shadow DOM 被成功禁用
